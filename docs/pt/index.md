# Guia de desenvolvimento

Aprende a construir o Lisamaria Studio por pequenas funcionalidades completas.

**Estado atual:** ferramental e um exemplo local de marcações. Uma única profissional; sem pagamentos, autenticação ou persistência definitiva. SIBS e atualizações entre vários clientes serão implementados numa fase seguinte.

## Percurso sugerido

1. **Começar:** executa o projeto e experimenta uma marcação.
2. **Vocabulário:** conhece os nomes usados no código e nos testes.
3. **Arquitetura:** acompanha uma ação desde o botão até ao domínio.
4. **BDD:** lê um cenário, executa-o e muda uma regra com intenção.
5. **Referência:** consulta assinaturas e detalhes quando precisares deles.
