# Developer guide

Learn to build Lisamaria Studio through small, complete features.

**Current state:** tooling and a local appointment example. One practitioner; no payments, authentication or permanent persistence. SIBS and updates across multiple clients will be implemented in a later phase.

## Suggested learning path

1. **Getting started:** run the project and try booking an appointment.
2. **Vocabulary:** learn the names used in code and tests.
3. **Architecture:** follow an action from the button to the domain.
4. **BDD:** read a scenario, run it and change a rule deliberately.
5. **Reference:** look up signatures and details when you need them.
